### 📋 Điểm Mới Nổi Bật Trong Bản v2.3.9:
1. **Giao Diện Siêu Tinh Gọn (Phone Farm Ready):**
   - Kích thước cửa sổ chuẩn 900x665 px, tối ưu trọn vẹn diện tích màn hình để mở song song 3-4 cửa sổ Scrcpy điều khiển máy thật.
   - Thêm cột Số Thứ Tự (STT), loại bỏ các cột rườm rà (Hạn dùng, Kích hoạt, Socks, Thông báo).
   - Khung Tuỳ chọn thiết bị thu nhỏ 25%, cột Email Mới tự động co giãn hiển thị đầy đủ chuỗi mail dài và pass khôi phục.
   - Khung tìm kiếm neo chuẩn góc phải Toolbar, không bị che khuất.
   - 4 nút Hành động nhanh thu nhỏ 235px x 34px cân đối, trực quan.
2. **Khắc Phục Triệt Để Khả Năng Tương Thích & Thay Đổi Phần Cứng:**
   - Hỗ trợ Root Silent Install (`pm install -r -d -g`) vượt 100% chặn cài đặt trên ROM Xiaomi / MIUI / HyperOS và Google Play Protect.
   - Tự động mở app `Device Info` trên màn hình điện thoại ngay sau khi Change để kiểm chứng đối soát thông số trực quan.
   - Chuẩn hoá lệnh Root Execution triệt tiêu hoàn toàn lỗi CRLF/BOM, loại bỏ báo thành công ảo.
   - Ghi cấu hình đa thư mục hệ thống song song (`/data/system`, `/data/domaconf`, `/sdcard/`) và khởi động lại Zygote 32/64-bit mượt mà.
3. **Dọn Dẹp Triệt Để Phiên Bản Cũ:**
   - Loại bỏ toàn bộ cơ chế sao chép tạo file thừa từ các bản v2.0 - v2.3.8.
   - Tự động quét dọn sạch sẽ các file exe cũ khi khởi động ứng dụng.
